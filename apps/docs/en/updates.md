---
title: App updates
description: Keep web and mobile clients on a supported version.
---

The web app mounts the static-hosting update banner. It offers a reload when an update is available.

## Web

Before asking someone to reload, consider whether they have unsaved work. Check that the reload opens the newly published app and preserves the expected session.

## Mobile

Expo Updates is the intended mobile update system. It is not configured in the current mobile workspace.

A native client needs an update policy, compatibility rules, and a clear point at which it can restart.

## Review

Verify an update on the actual client. Creating a new bundle alone does not prove that an existing installation receives and opens it.
