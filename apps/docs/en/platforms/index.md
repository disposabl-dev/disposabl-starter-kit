A Disposabl project can share its backend, accounts, and data across clients. Each client still needs its own screens and platform setup.

## Web

The web app uses React and TanStack Start. It includes public pages, documentation, and an authenticated area. Start with the [web guide](/docs/platforms/web).

## Mobile

The mobile workspace is intended for Expo and React Native. It is currently a placeholder, so native screens and authentication still need implementation. See [mobile apps](/docs/platforms/mobile).

## Other clients

The [HTTP API and MCP](/docs/interfaces) let external tools call selected backend operations. The [CLI](/docs/cli) and [SDK](/docs/sdk) are planned clients.

A desktop app is not included in this project. Treat desktop packaging as separate work.
