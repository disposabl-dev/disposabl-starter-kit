PostHog is the intended analytics provider. Tracking is not wired into the current app.

## Start with useful events

Choose a small set of actions that show whether people can complete the main task. See [events](/docs/analytics/events).

## Respect preferences

Connect optional tracking to a real consent choice before loading it. The current cookie banner describes essential cookies only.

See [consent and identity](/docs/analytics/consent).

## Related tools

- [Session replay](/docs/session-replay) helps inspect a user's path through a problem.
- [Crash analytics](/docs/crash-analytics) records errors.
- [Feature flags](/docs/feature-flags) controls rollouts.
- [Tracing](/docs/tracing) follows a request through services.

Each tool needs its own integration and verification.
